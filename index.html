Sobre este proyecto

Cine Juntos permite crear salas virtuales para compartir el momento de mirar una película, serie o video con otras personas, aunque estén lejos. Busca hacer más simple la experiencia de ver contenido juntos, coordinar la reproducción y conversar en un mismo lugar.

Parte técnica
Frontend estático en HTML, CSS y JavaScript vanilla. Usa HTML5 Video, sincronización en tiempo real con Firebase Realtime cuando está disponible y un transporte local como fallback.
