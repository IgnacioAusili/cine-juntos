Cine Juntos

              
Sobre este proyecto

            

          

          
        

        

          

            
Cine Juntos es un proyecto de código abierto (open source) concebido como una base con el propósito de la visualización sincronizada de contenido entre múltiples usuarios de manera comoda y sencilla. De manera tal, permite crear salas con un chat integrado, elegir el contenido a ver y cargarlo en un reproductor que tiene sus funciones sincronizadas entre todos los usuarios: reproducción, velocidad, pausa, etc.

            

              
              

                
Las salas se crean mediante un código de acceso que puede compartirse con otras personas, la reproduccion se sincroniza mediante Firebase Realtime y se puede incorporar el contenido a partir de archivos o enlaces directos alojados en servidores o CDN. Esta demo se publica en GitHub Pages mediante GitHub Actions.

                
Esta página funciona como una demostración funcional del proyecto. No incorpora publicidad ni restricciones propias, más allá de las limitaciones de los servicios utilizados o que utilice el usuario. El proyecto puede modificarse, adaptarse y alojarse según las necesidades del que quiera usarlo.

Parte técnica

              
Frontend estático en HTML, CSS y JavaScript vanilla. Usa HTML5 Video, sincronización en tiempo real con Firebase Realtime cuando está disponible y un transporte local como fallback.
